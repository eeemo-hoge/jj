# jj
This is generic version of  "find | grep" command. You can easily find files and jump it straight.

## Overview 
Simple and first.
This script would find your files locations and list on it. And jump into that files.

## System Requirements
- This program is designed to run on Linux.

## Development Environment
- Linux Mint 22.3 MATE.

## How to use
- Add this scripts line into bottom of your "~/.bashrc"
